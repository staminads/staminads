# v6.2.0

- Fix ClickHouse insert crash (`CANNOT_PARSE_NUMBER`) when a client sent a negative, fractional, or out-of-range screen/viewport dimension. Device metrics are now clamped to the `UInt16` range at ingest, so one malformed value can no longer fail an entire event batch flush.
- Fix a race condition when restoring the dashboard period and comparison from localStorage. Both values are now restored in a single navigation, so the saved period is no longer dropped, and values already present in the URL are preserved instead of being overwritten.
